# 🏏 IPL 2026 Ticket Booking Website

## About the Project

IPL 2026 Ticket Booking is a responsive website developed using HTML and CSS. It provides a simple interface for viewing match schedules and exploring ticket booking options.

## Features

* Navigation bar
* IPL 2026 banner
* Popular IPL teams
* Major match venues
* Match schedule table
* Team filter dropdown
* Ticket booking form
* Booking summary
* My Ticket Bookings section
* Stadium guidelines

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html.
4. Run using Live Server.
